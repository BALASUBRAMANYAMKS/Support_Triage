# Support_Triage
ORBIT SupportTriage is an end-to-end AI support ticket triage engine featuring hybrid RAG search (ChromaDB + BM25) and a 3-tier LLM fallback chain (Groq, Gemini). It enforces ITIL priority rules, regex PII redaction, and Pydantic validation. Powered by FastAPI and SQLite, it offers a Streamlit portal with an employee chatbot and agent audit trails.
