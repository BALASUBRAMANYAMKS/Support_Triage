# Malware / Virus: Defender quarantined a file downloaded from an unverified attachment: guided fix

## Symptoms
Since this morning, Defender quarantined a file downloaded from an unverified attachment; the employee has already signed out and back in.

## Cause
the file matches a known malicious signature

## Resolution
1. leave the file quarantined and let Security Operations verify the device
2. Confirm the service works from the affected device or account.
3. Record what changed and whether the issue returned.

## When to raise a ticket
Raise a ticket if these steps fail, the issue affects multiple people, or the service is business-critical. Include the exact error and affected device or app.
