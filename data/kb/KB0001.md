# Password Reset: a password reset link expires before use: guided fix

## Symptoms
a password reset link expires before use.

## Cause
an old browser session invalidates the reset token

## Resolution
1. clear the stale session and issue a fresh reset link
2. Confirm the service works from the affected device or account.
3. Record what changed and whether the issue returned.

## When to raise a ticket
Raise a ticket if these steps fail, the issue affects multiple people, or the service is business-critical. Include the exact error and affected device or app.
