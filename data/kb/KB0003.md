# Account Locked: unlock state has not synchronized: guided fix

## Symptoms
The account was unlocked in the directory, but the cloud application still reports it as locked.

## Cause
The unlock state has not propagated from the authoritative directory to the cloud identity tenant.

## Resolution
1. Confirm the authoritative account state, run the approved directory synchronization, and verify sign-in without asking for the password.
2. Confirm the service works from the affected device or account.
3. Record what changed and whether the issue returned.

## When to raise a ticket
Raise a ticket if these steps fail, the issue affects multiple people, or the service is business-critical. Include the exact error and affected device or app.
